# UI Autotests for SauceDemo

Автоматизовані UI-тести для навчального веб-ресурсу [SauceDemo](https://www.saucedemo.com/), розроблені з використанням Java та Maven.

---

## 🛠 Технологічний стек

* **Мова програмування:** Java (версія 11/17+)
* **Складання проєкту:** Maven
* **Фреймворк тестування:** JUnit / TestNG
* **Інструмент автоматизації:** Selenium WebDriver / Selenide
* **Звітність:** Allure Report
* **Паттерн проектування:** Page Object Model (POM)

---

## 🚀 Передумови та встановлення

Перед запуском переконайтеся, що у вас встановлено:
* **JDK:** версія 11 або вище
* **Apache Maven:** версія 3.6+
* **Браузер:** Google Chrome (актуальна версія)
